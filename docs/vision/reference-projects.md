# Reference Projects

Lyra should prove its architecture through substantial workloads rather than toy benchmarks.

## EV surround perception

A future reference workload will explore an edge perception system that can detect and track surrounding vehicles, estimate non-identifying physical attributes and relative motion, maintain temporal tracks, and estimate behavior such as persistent following with uncertainty.

The workload is intended to stress:

- camera and sensor ingestion
- computer vision and AI inference
- multi-object tracking
- ego-motion and sensor fusion
- realtime scheduling
- CPU/GPU/NPU execution
- constrained edge deployment
- profiling and power/latency budgets

A production road-safety system would require calibrated hardware, automotive safety engineering, validation, and appropriate standards compliance. This reference project is an architecture and research workload, not a current Lyra capability.
